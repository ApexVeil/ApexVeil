# Model assets

The checkpoint is downloaded independently from the official `facebook/sam3.1` repository at the revision in [manifest.json](manifest.json). Authenticate with your own Hugging Face account and obtain upstream access before downloading. We do not redistribute weights or authentication credentials.

Run `apexveil models download` from the project root. Files are stored here and ignored by Git. Run `apexveil models verify` to verify the pinned SHA-256. A failed verification must not be bypassed.
